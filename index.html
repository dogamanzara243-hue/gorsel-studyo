🚀 Kendi Colab GPU Grafik Linki Nasıl Alınır?

Ücretsiz T4 GPU • Kuyruk Yok

Ücretsiz bulut motorunda yoğunluk olduğunda kendi Google Colab T4 GPU sunucunuzu bağlayarak beklemeden sınırsız görsel üretebilirsiniz:

  1. Google Colab'de yeni bir not defteri açın.
  2. Üst menüden Çalışma zamanı → Çalışma zamanı türünü değiştir → T4 GPU seçip kaydedin.
  3. Aşağıdaki kodu kopyalayıp hücreye yapıştırın ve çalıştırın; oluşan https://xxxx.gradio.live linkini yukarıda "Kendi Colab GPU Sunucum" seçeneğine yapıştırın.

import torch, gc, gradio as gr
from diffusers import StableDiffusionPipeline

pipe = StableDiffusionPipeline.from_pretrained("runwayml/stable-diffusion-v1-5", torch_dtype=torch.float16).to("cuda")
pipe.safety_checker = None

def gorsel_uret(prompt, genislik, yukseklik, seed):
    gen = torch.Generator("cuda").manual_seed(int(seed))
    neg = "text, watermark, speech bubble, letters, blurry, low quality, deformed face, extra fingers"
    img = pipe(prompt, negative_prompt=neg, width=int(genislik), height=int(yukseklik), num_inference_steps=25, generator=gen).images[0]
    gc.collect(); torch.cuda.empty_cache()
    return img

with gr.Blocks() as demo:
    p, w, h, s = gr.Textbox(), gr.Number(value=512), gr.Number(value=896), gr.Number(value=42)
    gr.Button("Üret").click(fn=gorsel_uret, inputs=[p, w, h, s], outputs=gr.Image(type="pil"), api_name="gorsel_uret")

demo.launch(share=True)
